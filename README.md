# Tokyo 80s TRV30 CRT Hyprland Setup (0.57.1+ Lua)

Custom retro-futuristic Hyprland configuration featuring:
- **Hyprland 0.57.1+**: Fully native Lua configuration (`hyprland.lua`, `monitors.lua`).
- **Amber Monochrome CRT Aesthetic**: Custom VCR scanline shader, CRT tube curvature, mechanical 1-frame popin snap animations.
- **Tokyo Dual-Monitor Workspace Topology**:
  - `HDMI-A-1`: Workspaces 1-9
  - `eDP-1`: Workspaces 11-19
- **Modal Scratchpads**: Discord, Music (Spotify), Calendar, Notes, Dev, Radar, Display Deck with enforced 60px viewport margins.
- **Audio & System Daemons**: Smart split router, volume guards, cinema cursor, lid auto-detection.
- **Hyprctl Transparent Shim**: Drop-in wrapper bridging legacy CLI invocations to 0.57 Lua dispatcher.
